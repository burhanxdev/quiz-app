# JavaScript Quiz App 🧠

This is a simple, interactive, and responsive quiz application built using HTML, CSS, and JavaScript.

## 🌟 Features
- 20 General Knowledge Questions
- Clean and modern design
- Responsive layout
- Instant answer feedback
- Score tracking
- Progress bar
- Result messages
- Restart quiz functionality

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## 📂 Project Files
- `index.html` — The main structure of the webpage
- `style.css` — The styles and design of the webpage
- `script.js` — The quiz functionality and logic
- `questions.js` — Contains all quiz questions and answers

## 💻 How to View Locally
1. Download or clone this repository to your computer.
2. Open the project folder.
3. Run `index.html` using VS Code Live Server.
